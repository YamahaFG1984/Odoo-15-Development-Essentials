Odoo 是什么，为什么值得学

Odoo 是一套开源的企业管理软件（ERP）：销售、采购、库存、会计、项目、网站、电商……几十个应用共用一个数据库、一套界面。 对开发者来说，更重要的是它背后的框架：所有官方应用都是用同一套框架写出来的「模块」，你写的模块和它们地位完全平等， 可以新增功能，也可以修改任何已有功能。

🧩

一切皆模块

官方应用和你写的代码是同一种东西。扩展、覆盖别人的功能，不用改别人的源码。

🗃

强大的 ORM

用 Python 类定义数据，表结构自动创建、自动升级；记录集让数据操作像写普通 Python。

✍

声明式界面

表单、列表、看板用几行 XML 描述，不写一行前端代码就能得到完整的增删改查界面。

🌐

开源 + 生态

社区版开源（LGPL），还有 OCA 社区维护的上千个模块，以及庞大的实施和开发者网络。

这套教程写给谁

  • 会一点 Python，但没接触过 Odoo的开发者。每一章都从「这个东西是做什么的」讲起，而不是直接给 API。
  • 用过老版本 Odoo，想跟上新版本的人。大量章节里有「Odoo 15（书中写法）/ Odoo 20」的左右对照，附录还有一张完整的变化速查表。
  • 业务顾问、实施工程师：第 1 章不写代码，只用开发者模式就能做出一个应用；后面的章节帮你理解「界面背后发生了什么」。
ⓘ 需要什么前置知识

会写 Python 函数和类、了解一点 HTML 和 XML 的样子就够了。数据库只需要知道「表、行、列」这些概念。 命令行只需要会 cd 和敲命令；第 2 章会一步步带你在 Ubuntu（或 Windows 的 WSL）上搭好开发环境。

怎么用这套教程

  • 按顺序读。后面的章节建立在前面的模块之上。第 1 章不写代码，如果你急着动手，可以从第 2 章开始。
  • 亲手敲代码。每章末尾都有「动手练习」。看懂和写出来之间的差距，比你想象的大。
  • 留意紫色提示框。标着「⇪ Odoo 20 变化」的框说明这里和原书（Odoo 15）不同；如果你从没用过旧版本，把它当作「顺便了解一下历史」即可。
  • 左右对照卡片。左边是原书的 Odoo 15 写法，右边是 Odoo 20 写法。在网上搜到老代码时，这些对照能帮你一眼认出该怎么改。
  • 参考原书仓库的代码。本仓库的 ch02～ch15 和 final 目录是原书的 Odoo 15 代码，可以对照阅读，但直接安装到 Odoo 20 上会失败——请以教程里的代码为准。

💡 一句话总结

如果你只记住一件事：Odoo 里的一切——数据、界面、权限、菜单——都是某个模型里的记录，而模块就是一包「创建和修改这些记录」的代码与数据。 这套教程剩下的部分，都是在解释这句话的各种展开。
